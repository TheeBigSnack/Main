Every support request is answered within one business day: a reply with the fix, a workaround, or what happens next. A report about a Facebook warning is answered the same day with the same advice the posting rules give: stop posting and tell your manager. No promise is made about what Facebook will do.

What to send

  1. The report from the panel. When the side panel shows Couldn't fill, that list; or the text from Copy report on the dry run (Open the form and check fields only (nothing filled)). It says what the form showed, which is what the fix is made from.
  2. The version. The first line of Settings in the popup. A fix already shipped in a newer zip is the most common answer.
  3. The website. The address of the dealership's used inventory page, and the tab you were on when it happened.
  4. What was on screen. In your own words: which button you clicked, what the panel said, what Facebook showed. A screenshot of the panel is welcome. A screenshot of Facebook is fine only with no messages, buyer names or account details in it.

Never send a Facebook password, a cookie, a token, a two-factor code or a login link. Support never asks for them, and a request for one is a sign something is wrong.

Report a problem from the extension

In the popup, open Settings, then Report a problem, and click Copy problem report. It copies the version, the website, the adapter, the last scan, the last error and the field names of the last fill, for the same message as the panel's report. It contains no names, no cars and no listing links. Paste it into your message with the four items above.

Privacy requests

The privacy policy lets a dealership ask for its records to be exported or deleted, and a person ask for their own data to be deleted. Three request types:

  • Export a dealership's records. A manager of that dealership asks. The request comes from, or is confirmed by a reply from, the email of an account that is a manager of that dealership. The file goes to that address and nowhere else.
  • Delete a dealership. A manager of that dealership asks, verified as for an export, and then by a phone call to the dealership's main number, taken from its own website, before anything is deleted. A delete cannot be undone.
  • Forget a person. The person asks for themself, from, or confirmed by a reply from, the email of their own Lot Sync account.

The first reply goes out within one business day, like every request, and the request is finished within 30 days of being verified. Replies go to the address on the account, never to a new address the request gives; a request that cannot be verified gets a reply saying what is needed, and nothing is run until it is.

Three things the database cannot reach, so the request cannot cover them: your own browser (Settings has Clear everything for this website and Forget my synced profile), your listings on Facebook (yours to delete; Lot Sync never does), and copies your dealership already holds.

What support never does

  • Touch a salesperson's Facebook account: never logs in as them, never takes remote control of a Facebook tab, never publishes, edits, marks sold or deletes a listing for them, and never asks them to hand over the account for a quick look. If a listing must change, the salesperson changes it.
  • Ask for passwords, cookies, session tokens, two-factor codes or login links, for Facebook or for anything else.
  • Ask for buyer names, messages or anything from Marketplace conversations.
  • Tell a person that a listing is allowed or that Meta has signed off on anything. The honest line stays the same: a person clicking Publish is the safest design available, not a guarantee.
  • Install anything on a salesperson's computer other than the extension's zip, or change their Chrome settings beyond the install steps.
  • Send a dealership's export to anyone but the verified manager who asked, or delete anything for a request that has not been verified.
